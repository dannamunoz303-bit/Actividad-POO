# POO-JavaScript

Ejercicios de Programación Orientada a Objetos en JavaScript, basados en
https://www.w3resource.com/javascript-exercises/oop/index.php

| Archivo | Ejercicio | Conceptos |
|---|---|---|
| ejercicio1.js | Person | clases, encapsulación |
| ejercicio2.js | Rectangle | métodos, validación con setters |
| ejercicio3.js | Vehicle / Car | herencia, polimorfismo |
| ejercicio4.js | BankAccount | encapsulación |
| ejercicio5.js | Shape / Circle / Triangle | clase abstracta, polimorfismo |
| ejercicio6.js | Employee / Manager | herencia, sobrescritura |
| ejercicio7.js | Book / Ebook | herencia |
| ejercicio8.js | Animal / Dog | herencia, polimorfismo |
| ejercicio9.js | Bank | composición |
| ejercicio10.js | Product / PersonalCareProduct | herencia, atributos estáticos |
| ejercicio11.js | BankAccount (transferencias) | colaboración entre objetos |
| ejercicio12.js | University | composición |

## Ejecución

Requiere Node.js 14 o superior (por los campos privados `#`).

```bash
node ejercicio1.js
# o todos a la vez:
for f in ejercicio*.js; do echo "== $f =="; node "$f"; done
```
